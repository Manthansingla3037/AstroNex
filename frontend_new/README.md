# AstroNex Final Frontend

This frontend expects the existing AstroNex FastAPI backend at http://127.0.0.1:8000.

## Run

    cd /d C:\AstroNex\frontend_new
    npm install
    npm run dev

Open http://localhost:5173

## Notes
- Super Resolution uses the existing trained AstroNex LunarSR V2 backend endpoint.
- The comparison viewer keeps both images fixed and clips only the visible portion.
- Mineral images are illustrative sample visuals and must not be represented as validated IIRS mineral classifications.
